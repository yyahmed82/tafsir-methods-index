# مهارات هذا الفرع

| مهارة / أداة | لماذا | أين |
|---|---|---|
| Web Interface Guidelines | مراجعة الوصول والتفاعل (أهداف لمس، تركيز، أزرار لا `div`) | [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines) — النسخة المحلية إن وُجدت: `briefs/web-interface-guidelines.md` |
| WCAG 2.2 AA | تباين النص ≥ 4.5:1، هدف 24px، `aria-pressed`، `dir=ltr` للعناوين اللاتينية | [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) |
| Playwright | تحقق عناوين quranpedia.app، تدقيق 375/1440 × فاتح/داكن، لقطة `usage.png`، فحص لوحة المفاتيح | `docs/branches/build-ui-polish/shots/audit.py` |
| قوالب HTML ثم البناء | الصفحات المولَّدة لا تُحرَّر باليد | `src/*_template.html` ثم `src/build_fahras.py` / `build_methods.py` / `build_reconcile.py` |
| Diátaxis (how-to) | `HANDOFF.md` دليل تحقق لا مقالة | معيار الحزمة في جذر المستودع (حُذف بعد النسخ) |

لم تُستدعَ مهارات تعديل النص أو التصنيف أو الاعتماد؛ حدود الفرع واجهة فقط.
