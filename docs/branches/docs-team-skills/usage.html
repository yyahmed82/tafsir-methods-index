مهارات فريق مِرْقاة: دليل التشغيل والتنفيذ

حزمة مهارات المشروع لوكلاء الذكاء الاصطناعي (Claude Code / Codex): بناء العرض النهائي، تسجيل الفيديو التعريفي، ومراجعة طلبات السحب
بناء العرض النهائي (mirqah-deck-build) توليد العرض النهائي ومعالجة ثنائية الاتجاه إجبارياً، وملء علامات التحديث بالأرقام الحقيقية، ومراجعة الشرائح بصرياً.
تسجيل الفيديو التعريفي (mirqah-demo-recording) تسجيل مرئي بمنتج حقيقي وبث حي للطرفية (≤ دقيقتين)، بالسمة الفاتحة، وفق جدول VO v3 ولائحة لقطات Playwright.
مراجعة طلبات السحب (mirqah-pr-review) مراجعة مستقلة عدائية، واختبار سلبي يفشل على main وينجح على الفرع، وحظر المساس ببيانات data/** وحكم PASS/BLOCK.
1

تحميل المهارات

نسخ مهارات المشروع إلى مجلد مهارات الوكيل في بيئة العمل.

Copy-Item -Recurse docs/team/skills/* $HOME/.claude/skills/
النتيجة: التعرف على المهارات الثلاث وظهورها في بيئة الوكيل.
توقف إن لم تظهر: تحقق من صحة مسار المهارات قبل البدء.
2

بناء العرض التقديمي

بناء الشرائح ثم تشغيل سكريبت معالجة الاتجاه إجبارياً.

python build_final.py python fix_bidi.py in.pptx out.pptx
النتيجة: ملف عرض متناسق وضبط رموز اللغة بدون انعكاس الأقواس.
توقف إن فُقدت خطوة المعالجة: لا تسليم بدون تشغيل fix_bidi.
3

أتمتة لقطات الفيديو

تسجيل لقطات المتصفح بدقة محددة وبالسمة الفاتحة في وضع حي.

python -m playwright codegen --viewport-size=1920,1080 mirqah.app
النتيجة: مشاهد حقيقية متزامنة مع نص التعليق الصوتي المعتمد.
توقف إن ظهرت الطرفية في وضع محاكاة: وضع LIVE إلزامي.
4

حراسة البيانات والمصدر

التحقق من عدم المساس بأي ملفات نصية أو طبقات مصدرية.

git diff origin/main -- data/
النتيجة: ناتج فارغ تماماً يؤكد ثبات البيانات المصدرية.
توقف إن ظهر أي تعديل في data: الرفض الفوري لطلب السحب.
5

المراجعة المستقلة

إثبات الاختبار السلبي على الكود القديم ثم التحقق من الكود الجديد.

git checkout origin/main -- src/ python -m pytest -q git checkout HEAD -- src/ python -m pytest -q
النتيجة: فشل على القديم ونجاح على الجديد وحكم PASS موثق.
توقف إن نجح الاختبار على القديم: الاختبار شكلي ويُرفض.
ما لا يفعله هذا الفرع: لا تعديل على كود المحرك أو البيانات المصدرية، لا نسب مئوية (% أو ٪)، لا ادعاء دقة، لا كلمة «الأول» للسبق، ولا اعتماد آلي — «اعتماد» محجوز للمتخصص البشري.
كيف تعرف أنه يعمل: وجود مجلدات المهارات الثلاث بمستنداتها الكاملة، وتطابق بوابات الفحص الصارمة، وإصدار أحكام المراجعة بتقرير موثق ومحدد المسار والسطر.
